============================================================
מדריך להקמת שרת FTP מקומי ובדיקת מצלמת Hikvision
============================================================

הקבצים המצורפים בתיקייה זו נועדו לעזור לך להרים שרת FTP מהיר על המחשב שלך
ולבדוק את קבלת התמונות (Snapshots) מהמצלמה/NVR של Hikvision בזמן אמת.

תוכן התיקייה:
1. קובץ הוראות מפורט זה (README.txt)
2. סקריפט Python להרמת שרת FTP קל משקל ברגע (ftp_server.py) - אופציה א' (מומלצת ומהירה)

------------------------------------------------------------
אופציה א': הרמת שרת FTP מהירה באמצעות Python (תוך 10 שניות)
------------------------------------------------------------
אם מותקן אצלך Python במחשב, זו הדרך הכי מהירה ללא התקנות מורכבות:

צעד 1: פתח את תרמינל / שורת הפקודה (CMD) בתיקייה זו.
צעד 2: התקן את ספריית ה-FTP על ידי הרצת הפקודה הבאה:
       pip install pyftpdlib

צעד 3: הרץ את הסקריפט המצורף:
       python ftp_server.py

צעד 4: השרת פעיל! הוא פתח אוטומטית תיקייה בשם "hikvision_images" בתוך התיקייה הנוכחית.
       פרטי החיבור למצלמה יהיו:
       - Server Address: כתובת ה-IP של המחשב שלך (הסבר למציאה בהמשך)
       - Port: 2121
       - User Name: hikvision
       - Password: CHANGE_ME_FTP_PASSWORD

------------------------------------------------------------
אופציה ב': שימוש בתוכנת גרפית - FileZilla Server
------------------------------------------------------------
אם אתה מעדיף ממשק גרפי מלא:

צעד 1: הורד את "FileZilla Server" מהאתר הרשמי: https://filezilla-project.org/
צעד 2: התקן את התוכנה עם הגדרות ברירת המחדל (לחץ Next).
צעד 3: פתח את ממשק הניהול ולחץ על Connect.
צעד 4: גש ל-Server -> Configure -> Users.
צעד 5: לחץ Add, צור משתמש בשם "hikvision", ושנה את ה-Credentials ל-Password: "CHANGE_ME_FTP_PASSWORD".
צעד 6: תחת Mount Points, לחץ Add. ב-Virtual Path שים "/" וב-Native Path בחר תיקייה ריקה במחשב.
צעד 7: סמן V על הרשאות Read ו-Write ולחץ OK. השרת מקשיב בפורט 21.

------------------------------------------------------------
איך למצוא את כתובת ה-IP של המחשב שלך (IPv4):
------------------------------------------------------------
1. לחץ על מקש Windows + R, הקלד cmd ולחץ Enter.
2. בשורת הפקודה הקלד: ipconfig ולחץ Enter.
3. חפש את הכרטיס הרשת הפעיל שלך (Ethernet או Wi-Fi) ותחתיו את השורה:
   IPv4 Address . . . . . . . . . . . : 192.168.X.X
4. זו הכתובת שתזין במצלמה בשדה "Server Address".

------------------------------------------------------------
הגדרות בממשק ה-Web של Hikvision:
------------------------------------------------------------
1. עבור אל Configuration -> Network -> Advanced Settings -> FTP.
2. מלא את הפרטים:
   - Server Address: ה-IP של המחשב שלך (למשל 192.168.90.X)
   - Port: 2121 (אם השתמשת בסקריפט הפייתון) או 21 (אם השתמשת ב-FileZilla)
   - User Name: hikvision
   - Password: CHANGE_ME_FTP_PASSWORD
   - Directory Structure: בחר ב-"Save in the child directory" (נוח ומסודר לפי תאריך)
   - ודא שסעיף "Upload Picture" מסומן ב-V בתחתית!
3. לחץ על כפתור Test. 

ברגע שהטסט מצליח, גש למצלמה, תפעיל את ה-Smart Event (חציית קו / זיהוי תנועה) ותראה את התמונות זורמות למחשב שלך!
